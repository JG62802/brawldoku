## 3. Audit of Failing Puzzles

### List of Failing Puzzles (<2 Valid Answers)
**NONE.** 

There are zero daily puzzles in the production game that contain fewer than 2 valid brawlers for any cell.

### Why No Failing Puzzles Occur in Production
During puzzle generation (`generateDailyPuzzle` in `src/engine/puzzleGenerator.ts`), candidate 3×3 grids are validated by `hasDisjointSolution(rows, cols, 2)`:
1. Every intersection $(r, c)$ calculates `getMatchingBrawlers(rows[r], cols[c])`.
2. If `matches.length < 2`, the grid is **immediately rejected** (`valid: false`), discarding any category combination that would yield 0 or 1 valid answer.
3. A backtracking solver then verifies that a complete set of 9 distinct, non-overlapping brawlers can simultaneously solve all 9 cells.
4. If a candidate passes both checks, it is emitted as the canonical daily puzzle.

## 5. Game Engine Answer Acceptance Verification

To guarantee that multiple answers are actually accepted by the live game engine and not merely counted in an abstract audit:
- In `src/engine/gameEngine.ts`, `submitGuess()` computes:
  ```ts
  const rowCat = CATEGORY_BY_ID[state.rowCategoryIds[row]];
  const colCat = CATEGORY_BY_ID[state.colCategoryIds[col]];
  const isValid = rowCat.predicate(brawler) && colCat.predicate(brawler);
  ```
- This predicate logic is identical to `getMatchingBrawlers(rowCat, colCat)`.
- Vitest automated tests verify that every brawler identified by `getMatchingBrawlers` successfully registers as `correct: true`, awards points, locks into the cell, and consumes exactly 1 guess.
